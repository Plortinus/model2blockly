# Generated Blockly Editor

Input model: `examples/feature_pairs/01_basic_structure/source.ecore`

Output: EMF EditorSpec intermediate XMI and HTML Blockly editor

## Start Here

1. Open `generation_report.html` to inspect the model-to-Blockly mapping.
2. Open `html/BasicStructure_standalone.html` in a browser to use the generated HTML editor.
3. Inspect `intermediate/*_blocklyspec.xmi` to see the EMF intermediate model used for generation.
4. Click `Load Sample` or import `html/sample_model.json` to inspect a representative domain instance.

## Typical Iteration

- Edit the Ecore or `.m2b` source when the domain structure should change.
- Add Blockly/UI/code annotations when block labels, layout, widgets or code templates need refinement.
- Rerun this Eclipse action and reopen `generation_report.html`.
