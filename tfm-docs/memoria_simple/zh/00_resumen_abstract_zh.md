# 摘要与 Abstract 中文审阅稿

## 西语 Resumen 的中文意思

本硕士毕业论文研究如何创建具有积木式语法的领域特定语言。论文的主要动机是：Blockly 这样的库虽然可以帮助开发者构建视觉化编辑器，但开发者仍然需要手动用 JavaScript 定义积木、字段、连接、工具箱、验证规则和生成器。每当需要为一个新领域创建编辑器时，这些工作都会重复出现。

为减少这种重复劳动，论文提出了 BlocklyDSL，一个生成式环境，可以把抽象的领域描述转换为可执行的 Blockly 编辑器。该工具支持两条输入路线：一种是 Ecore 元模型，可以通过注解补充信息；另一种是用 Xtext 定义的文本 DSL。两条路线都会被统一转换到一个公共的中间模型，其中表示积木、字段、类别、值输入、引用、验证规则和界面元数据。基于这个规格，系统可以生成 HTML/JavaScript 编辑器。生成的编辑器可以在浏览器中打开，并支持保存、加载、导出和运行时验证提示。

论文通过 AppMaker 这个 running example 评估方案，并分别用文本 DSL 和带注解的 Ecore 两条路线实现同一个领域。该例子覆盖页面、组件、动作、导航、数据源、包含关系、继承、抽象类、动态引用、必填字段检查、简单验证规则和代码模板。此外，项目包含按层组织的 142 个 JUnit 测试。结果表明，BlocklyDSL 能够从高层模型或 DSL 生成 Blockly 编辑器，减少底层手工编程，同时保持可扩展的架构。

## English Abstract 的中文意思

英文摘要与西语摘要内容一致，主要说明：本论文提出 BlocklyDSL，用模型驱动和语言工程的方法，把 Ecore 元模型或文本 DSL 描述转换为可执行的 Blockly 编辑器。评估部分使用 AppMaker 的 DSL/Ecore 双路线和 142 个 JUnit 测试证明该方案不是手写单一编辑器，而是一套可以复用的生成架构。
